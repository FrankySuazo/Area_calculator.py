# 📐 Area Calculator

A simple command-line area calculator built with Python. This project calculates the area of four geometric shapes using user input, conditional statements, and mathematical formulas.

## Features

- Calculate the area of a triangle, rectangle, square, or circle.
- Interactive menu for selecting a shape.
- Accept user input for shape dimensions.
- Display the calculated area.
- Option to exit the program.

## Technologies Used

- **Python 3**
- **Math module** (optional, for calculating π)
- **Conditional statements** (`if`, `elif`, `else`)
- **User input** (`input()`)
- **Arithmetic operations**

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/FrankySuazo/Area_calculator.py.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Area_calculator.py
   ```

3. Run the program:

   ```bash
   python area_calculator.py
   ```

## Mathematical Formulas

| Shape | Formula |
|-------|---------|
| Triangle | Area = (Base × Height) / 2 |
| Rectangle | Area = Length × Width |
| Square | Area = Side² |
| Circle | Area = π × Radius² |
